How it works

Python secrets uses cryptographic randomness. Candidates are generated from the selected alphabet until every selected group is represented.

FAQ

Is strength guaranteed?

No. Length and randomness help, but safe storage and avoiding reuse matter too. The entropy estimate counts valid outputs under the selected character rules; it assumes a sound random source. It is not a promise about password storage or reuse. There is no weak random fallback.
