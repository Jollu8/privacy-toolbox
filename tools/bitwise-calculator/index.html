About this tool

Convert HEX, DEC and BIN; inspect signed integers, masks and bit shifts.

How it works

Python integer arithmetic preserves all 64 bits. NOT and left shifts are masked to the selected width. Logical right shift inserts zeros; arithmetic right shift extends the sign bit.

FAQ

Does this reproduce every C++ expression?

No. These are explicit fixed-width operations, not C++ integer promotions or overflow rules. Shift counts must be smaller than the width. Both signed and unsigned interpretations are shown.
