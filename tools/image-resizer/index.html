About this tool

Change image dimensions with aspect ratio controls and quick presets.

How it works

Pillow resizes oriented pixels with Lanczos resampling. Percentage presets use original dimensions; pixel presets limit the longest side without upscaling.

FAQ

What is the size limit?

Input and output are limited to 20 megapixels. With Keep aspect ratio enabled, the last edited dimension determines the other dimension.
