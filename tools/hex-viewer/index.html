About this tool

Inspect file bytes as HEX and ASCII, and decode little-endian or big-endian integers.

How it works

Each row contains an absolute byte offset, sixteen hexadecimal bytes and printable ASCII. Integer decoding uses the first word at the selected offset. Change byte order to compare interpretations.

FAQ

Does this modify the file?

No. The viewer only reads bytes. Reversed bytes are shown separately. Non-printable bytes appear as dots in ASCII; their hex values remain unchanged.
