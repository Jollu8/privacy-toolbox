About this tool

Calculate SHA-256, SHA-512, and other checksums without uploading your file.

How it works

Python hashlib updates one digest from 4 MiB chunks. The next chunk is read only after the previous one is processed.

FAQ

Can I hash a large file?

Yes. Hashing reads bounded chunks and reports progress instead of loading the entire file into memory. You can cancel at any time.
