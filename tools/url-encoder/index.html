About this tool

Percent-encode a query value or decode UTF-8 URL text.

How it works

Python urllib.parse quotes or unquotes UTF-8 bytes. Invalid percent escapes and invalid decoded UTF-8 are rejected.

FAQ

Should I encode a full URL or a parameter?

Use query parameter mode for individual values such as search text. Full URL mode preserves separators such as /, ?, and &.
