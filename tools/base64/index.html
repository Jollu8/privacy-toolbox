About this tool

Encode and decode UTF-8 text or binary files with Base64.

How it works

Python base64 performs strict decoding with whitespace allowed. Text is UTF-8; file modes preserve arbitrary bytes.

FAQ

Why does text decoding fail for some inputs?

The decoded bytes may be a binary file rather than UTF-8. Choose Base64 → file to download them.
