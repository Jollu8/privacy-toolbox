About this tool

How it works

Python difflib produces a unified line diff. Missing final newlines are marked explicitly. User content is displayed as text, never interpreted as HTML.

FAQ

Can I cancel a long comparison?

Yes. Cancel terminates the Worker and the next operation starts a fresh engine.
