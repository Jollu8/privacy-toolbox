About this tool

Inspect IPv4 and IPv6 subnets, compare addresses and merge network lists.

How it works

Python ipaddress calculates masks and ranges without enumerating hosts. Comparison checks address membership or network overlap. Merging combines only adjacent or overlapping networks without adding addresses.

FAQ

How are IPv6 and point-to-point links handled?

IPv6 has no broadcast address. Host ranges exclude subnet-router anycast except for /127 and /128. IPv4 /31 includes both addresses and /32 includes its single address. These ranges are not a check of address availability.
