A SMALL TOOLKIT. A CLEAR PROMISE.

Your files are
your business.

Privacy Toolbox brings everyday utilities to your browser, with Python doing the work on your device.

Local by design

Files and text pass from the page to a Web Worker, where Python runs through Pyodide and WebAssembly. Results return to the page for copying or downloading. There is no upload endpoint, account system, analytics, advertising, or application storage of your input.

Your language preference is saved in this browser. Tool input is never saved.

What connects to the internet?

Your browser requests this static site from its host. When you first run a tool, it downloads Pyodide 0.29.3 from jsDelivr. Image tools additionally download Pillow. These requests expose ordinary connection information, such as your IP address, to the hosting and CDN providers. Your files and tool input are not included.

This release requires a connection to load its runtime. It does not promise offline operation. Browser extensions, your device, clipboard, and downloaded files remain outside the app’s control.

Simple tools, honest limits

Hashing reads files in 4 MiB chunks. Other files are limited to 64 MiB, text to 8 MiB, and images to 20 megapixels to manage browser memory. Animated images are rejected. Metadata removal re-encodes pixels and removes embedded EXIF, GPS, text, and color profiles; it cannot remove details visible in the picture. JPEG re-encoding is lossy.

URL cleaning removes a fixed list of known parameters, not every possible tracking technique. MD5 and SHA-1 are provided for legacy checksum comparison and are unsuitable for cryptographic security. Base64 does not encrypt data.

Built to be inspectable

The site uses plain HTML, CSS, JavaScript, and Python. QR generation uses a bundled local Nayuki JavaScript library without loading Python. Passwords and tokens use cryptographic randomness. JWT decoding does not verify signatures. No framework or backend is required. You can inspect the worker source and Python dispatcher directly.

Built with Pyodide and Pillow.
